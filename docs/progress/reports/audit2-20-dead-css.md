# Dead CSS audit — quarry

## Method

Computed `defined \ used` from `src/**/*.css` class tokens vs class tokens extracted from `className=` in `src/ui/**/*.tsx` and `website/**/*.tsx`, using the same balanced-brace extractor as `scripts/unstyled-classes.ts`. A class counted "used" only if it survives the unstyled-class extractor's literal/template-hole rules. For every candidate I then ran `rg` across the whole repo (src, src-tauri, website, excluding CSS) for any raw occurrence, and read the definitions for the survivors.

Total CSS class tokens: 713. Tokens not in any tsx `className=`: 111. Tokens with zero raw occurrences outside of CSS: 23 (safe-to-delete set below).
