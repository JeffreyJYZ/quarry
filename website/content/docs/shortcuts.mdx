# Keyboard shortcuts

The window's accelerators are registered on the capture phase, so they work wherever focus sits —
except where a text field or the terminal owns the key, which is the point.

This page is not a transcript. It renders `SHORTCUT_GROUPS` from
`src/ui/app/shellShortcuts.ts`, the array the in-app sheet draws, so a key added there appears here
without an edit.

A native menu accelerator wins over an in-app binding with the same chord: a row marked menu opens
the menu action, and a note names any in-app command that lost its chord.
